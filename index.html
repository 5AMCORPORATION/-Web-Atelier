FAQ

Preguntas.

¿La página de muestra se puede modificar?

Sí. La muestra sirve como punto de partida. El contenido, imágenes, información, colores y diferentes elementos pueden adaptarse al negocio.

¿La cotización es una compra?

No. El formulario solamente envía una solicitud de cotización por WhatsApp. Antes de realizar cualquier pago se confirmarán el precio, alcance y condiciones del proyecto.

¿Qué sucede después del pago?

Una vez confirmado el proyecto y realizado el pago correspondiente, se solicitarán los textos, imágenes, datos de contacto y demás información necesaria para preparar el sitio.

¿Puedo solicitar otro tipo de página?

Sí. La colección irá creciendo y también puedes solicitar una propuesta para un tipo de negocio que todavía no aparezca en el catálogo.

¿Qué métodos de pago manejan?

Puedes indicar tu método de preferencia durante la solicitud. El método disponible y las condiciones se confirmarán directamente por WhatsApp.
