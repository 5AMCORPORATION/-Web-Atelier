Preguntas

Antes de comenzar.

¿Estoy comprando exactamente la página de muestra?

La muestra funciona como referencia del diseño y funcionamiento. El sitio puede requerir personalización dependiendo de las necesidades de tu negocio. Antes de comenzar se confirmarán los detalles de tu proyecto.

¿Puedo modificar la información?

Sí. Después de realizar el pago se solicitarán los datos, textos, imágenes, información de contacto y demás elementos necesarios para preparar la página.

¿Cómo realizo el pago?

Durante la cotización podrás indicar el método de pago que prefieras. El método disponible y las condiciones finales se confirmarán directamente por WhatsApp antes de realizar cualquier pago.

¿Qué información necesito proporcionar?

Una vez confirmado el proyecto se solicitará la información necesaria para construir o personalizar el sitio, como textos, imágenes, datos de contacto, redes sociales, horarios, servicios y cualquier otro contenido necesario.

¿Puedo pedir una página que todavía no aparece aquí?

Sí. La colección está diseñada para crecer. Si necesitas un tipo de página que todavía no aparece en el catálogo, puedes solicitar una propuesta directamente por WhatsApp.
